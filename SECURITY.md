# Security Policy

## Reporting a Vulnerability

Please do not open a public issue for security vulnerabilities. Use GitHub's
private vulnerability reporting ("Security" tab > "Report a vulnerability") on
this repository, or contact the maintainers through Sanofi's usual security channels.

## Supported Versions

Only the latest released version of CImpact receives security fixes.

## Dependency and Code Scanning

Dependencies are audited with `pip-audit` on every push and pull request, and
Dependabot proposes weekly updates for Python packages and GitHub Actions.
